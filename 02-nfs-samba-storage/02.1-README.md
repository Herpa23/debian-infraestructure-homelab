# Módulo 02: Almacenamiento en Red (NFS y Samba)

Este módulo documenta la implementación y configuración de servicios de almacenamiento compartido en la máquina virtual `debian-infra`. El objetivo es habilitar repositorios centralizados de archivos accesibles desde el equipo host de la infraestructura, utilizando dos protocolos estándar de la industria según el caso de uso: **NFS (Network File System)** para entornos Linux de alta eficiencia y **Samba (SMB/CIFS)** para compatibilidad multiplataforma.

---

## 1. Introducción y Elección de Protocolos
Antes de la implementación, es fundamental definir el propósito de cada protocolo en el diseño de la arquitectura:
- **NFS (Network File System):** Diseñado nativamente para sistemas operativos tipo Unix/Linux. Ofrece un rendimiento superior, bajo overhead de red y un modelo de permisos basado en UID/GID transparente. Ideal para compartir directorios de trabajo o volúmenes de datos directamente con la máquina host o clientes Linux del laboratorio.
- **Samba (SMB/CIFS):** Protocolo estándar para compartir archivos en redes mixtas. Permite que sistemas operativos Windows (como el equipo host físico) monten y accedan a los recursos compartidos de manera nativa utilizando autenticación por credenciales de usuario.

## 📁 Estructura del Módulo

1. **[NFS (Network File System)](./nfs-server-client.md)**
   - Configuración del servidor NFS en Debian 12.
   - Diseño de permisos colaborativos mediante el bit SetGID (`2755`).
   - Restricción de puertos y perfiles de aplicación en UFW.
   - Configuración del cliente, opciones de seguridad en `/etc/fstab` (`noexec`, `nosuid`, `nodev`, `_netdev`) y pruebas de validación.

2. **[Samba (SMB/CIFS)](02.3-samba-server-client.md)**
   - Implementación del servidor Samba para compatibilidad multiplataforma con Windows.
   - Gestión de usuarios y credenciales de red dedicadas (`smbpasswd`).
   - Configuración de recursos compartidos (`smb.conf`) y apertura de puertos perimetrales en UFW.
